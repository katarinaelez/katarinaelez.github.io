<h2>Overview</h2>

<p>
This project focused on the computational classification of protein-protein interfaces as biologically relevant or crystallographic artifacts. The work includes the development of a method for interface classification {% cite elez_distinguishing_2018 %}, its implementation as a fast and user-friendly web server for practical use {% cite jimenez-garcia_prodigycrystal_2019 %}, and a comprehensive review of computational approaches to interface classification, covering energy-based, empirical, and machine learning methods {% cite elez_biological_2020 %}.
</p>

<h2>Key Contributions</h2>

<ul>
<li>Analyzed structural and energetic differences between biological and crystallographic interfaces.</li>
<li>Developed predictive models achieving high accuracy for interface classification.</li>
<li>Contributed to PRODIGY-CRYSTAL, a fast and accessible web tool for interface prediction.</li>
<li>Systematically reviewed computational methods for protein interface classification.</li>
</ul>

<h2>Background</h2>

<p>
Protein-protein interactions are central to cellular function, and their structural characterization is essential for understanding biological mechanisms. X-ray crystallography provides many protein complex structures, but crystallographic packing often introduces non-biological interfaces that must be distinguished from biologically relevant ones. This distinction is challenging due to overlapping structural and energetic features, motivating computational approaches for reliable interface classification.
</p>

<h2>Methodology</h2>

<ul>
<li>Analysis of intermolecular residue-residue contacts</li>
<li>Protein-protein interface refinement</li>
<li>Machine learning-based classification</li>
</ul>
